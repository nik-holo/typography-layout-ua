# Типографська розкладка для українських користувачів Mac

Адаптація [типографської розкладки Іллі Бірмана](https://ilyabirman.ru/typography-layout/) з підтримкою української мови. Дві версії кириличної розкладки, залежно від того, яка мова у вас основна: літери другої мови набираються через ⌥ (option), основної — без нього.

![alt tag](https://cloud.githubusercontent.com/assets/1838329/14048294/089a4988-f2b6-11e5-88b2-95217219f231.png)

Видалено єбучій серп і молот, замінено на приємні крапки. Принцип кольорової диференціації залишився незмінним: червона крапка — кирилична розкладка, сіра крапка — англійська.

## Установка

### Через Homebrew

```sh
brew tap nik-holo/typography-layout-ua https://github.com/nik-holo/typography-layout-ua
brew trust nik-holo/typography-layout-ua
brew install --cask typography-layout-ua
```

`brew trust` потрібен у Homebrew 7+ для сторонніх tap-ів. Homebrew попросить пароль, бо розкладки ставляться у `/Library/Keyboard Layouts` для всіх користувачів.

### Через інсталятор

Завантажте `typography-layout-ua-<версія>.pkg` з [останнього релізу](https://github.com/nik-holo/typography-layout-ua/releases/latest) і запустіть його. Пакет не підписаний, тож macOS може попросити підтвердити запуск у System Settings → Privacy & Security.

### Вручну

Скопіюйте файли `*.keylayout` та `*.icns` у `/Library/Keyboard Layouts` (Cmd+Shift+G у Finder, вставте адресу):

- `Russian.keylayout` — з основною російською мовою
- `Ukrainian.keylayout` — з основною українською мовою
- `Enghlis.keylayout` — англійська

Можна скопіювати обидві кириличні та вибрати потрібну.

### Після установки

Якщо раніше ви копіювали `*.keylayout` вручну, видаліть старі файли з `/Library/Keyboard Layouts`, інакше розкладки будуть у списку двічі.

1. Перезавантажте систему або вийдіть з акаунта та зайдіть знову.
2. System Settings → Keyboard → Input Sources → Edit → «+».
3. Додайте потрібні розкладки, видаліть зайві.

Іконки можна замінити на будь-які інші з комплекту, просто перейменувавши файли `.icns`.

## Використання

Щоб ввести літери другої мови, затисніть ⌥:

| Комбінація | Результат |
|---|---|
| ⌥ + ы | і |
| ⌥ + ъ | ї |
| ⌥ + э | є |
| ⌥ + ё | ґ |
| ⌥ + g | ₴ |

І навпаки на розкладці з основною українською.

### Додано з версії 3.9 розкладки Бірмана

| Комбінація | Результат |
|---|---|
| ⌥ + з / P | ′ (штрих: хвилини, фути) |
| ⇧⌥ + з / P | ″ (подвійний штрих: секунди, дюйми) |
| ⇧⌥ + 9 і 0 | ‹ › (одинарні ялинки, замість 〈 〉) |
| ⌥ + ц / W | ✓ |
| ⇧⌥ + ц / W | ⌃ |
| ⇧⌥ + у / E | ⌥ |
| ⇧⌥ + е / T | # |
| ⇧⌥ + р / H, потім літера | ˝ подвійний акут: ő ű Ő Ű, ӳ Ӳ |
| ⇧⌥ + S (лише англійська) | ⇧ |

Символ ⇧ на кириличних розкладках не додано: у Бірмана він на ⇧⌥ + ы, а тут ця комбінація дає І / Ы.

## Як вимкнути розкладку «US»

1. Додайте японську розкладку.
2. Видаліть основну.
3. Видаліть японську.
4. Замовте піцу і відсвяткуйте це :)

## Розробка

Джерело правди — файли `*.keylayout` у корені репозиторію (редагуються в [Ukelele](https://software.sil.org/ukelele/)).

- `./build.sh` збирає `dist/Typography Layout UA.bundle`, zip для Homebrew та `.pkg`.
- `./release.sh <версія>` оновлює `VERSION` і sha256 у cask, робить коміт і тег, публікує GitHub-реліз з zip та pkg.
